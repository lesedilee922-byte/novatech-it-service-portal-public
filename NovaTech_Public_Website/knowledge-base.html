NETWORK

Wi-Fi is not working

  1. Make sure Wi-Fi is switched on and airplane mode is off.
  2. Reconnect to the correct company network.
  3. Check whether other devices can connect.
  4. If permitted, restart the device and test again.
  5. If the issue continues, log a ticket and include your location.
Still not working? Submit a ticket →
HARDWARE

Printer will not print

  1. Check printer power and connection.
  2. Check paper, toner or ink, and display alerts.
  3. Confirm the correct printer is selected.
  4. Check the print queue for stuck jobs.
  5. Do not force paper out; follow the printer's jam instructions.
Still not working? Submit a ticket →
PERFORMANCE

Computer is running slowly

  1. Save your work.
  2. Close unnecessary applications and browser tabs.
  3. Check available storage space.
  4. Restart only when safe to do so.
  5. Note when the slowdown occurs and report repeated problems.

IT GOVERNANCE

Change Request Process

A change request is used when an IT system, device, configuration, or service needs a planned modification.

1
Request

Describe the proposed change, reason, affected systems, and expected benefit.

2
Assess

Document risks, impact, resources, implementation time, and a rollback plan.

3
Approve

Obtain approval from the authorised person before implementation.

4
Implement and review

Make the approved change, test it, record the result, and update documentation.
